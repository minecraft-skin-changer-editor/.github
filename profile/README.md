## Troubleshooting Common Issues

Install issues? Run the tool as administrator if it needs to write to the game directory.  
Performance problems? Close the game before uploading a skin so the profile refresh is not locked.  
License/activation? Sign out and back in if the launcher rejects the session token.  
Compatibility? Match the model type in the editor to the one selected on the account.  
Update failures? Re-export the PNG at exactly 64x64 if the upload fails validation.
